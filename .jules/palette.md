## 2024-05-17 - Add tooltips to icon-only buttons
**Learning:** In Flutter, adding a `tooltip` property to an `IconButton` serves a dual purpose: it provides a visual hover label for desktop/web users and acts as the semantic label for screen readers. It is a simple and effective way to ensure accessibility without complex widget wrappers.
**Action:** Always include a `tooltip` property when using `IconButton` widgets, especially for clear, common actions like toggling password visibility or clearing search fields.
