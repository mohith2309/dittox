## 2024-05-24 - SSRF Protection via URL parsing
**Vulnerability:** The webhook outbox function (`sendWebhook`) previously accepted any user-provided URL without validation, allowing attackers to perform Server-Side Request Forgery (SSRF) to scan internal network infrastructure or access cloud metadata endpoints like `169.254.169.254`.
**Learning:** Naive URL string matching can be bypassed using obfuscation (e.g. hex, octal, decimal IP encoding). The safest approach is to utilize native Node.js `URL` object parsing which naturally normalizes IP addresses. Furthermore, explicitly blocking HTTP redirects via `redirect: "error"` in `fetch` is essential because an attacker could point to a valid domain that immediately redirects to an internal endpoint, bypassing the initial URL validation.
**Prevention:** Always validate all outbound URLs against a denylist of private/internal IP ranges, verify the protocol is http/https, and enforce `redirect: "error"` on the fetch request.
