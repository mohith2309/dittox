## $(date +%Y-%m-%d) - [Flattened Nested ListViews]
**Learning:** Found a recurring Flutter performance anti-pattern in the codebase: nesting a `ListView.builder` with `shrinkWrap: true` and `physics: NeverScrollableScrollPhysics()` inside a parent `ListView`. This setup completely defeats list virtualization, forcing Flutter to synchronously measure and instantiate all items in the list instead of just the visible ones.
**Action:** Always flatten nested `ListView` structures into a single `ListView.builder` handling different indices for headers, empty states, and list items. This restores lazy loading (virtualization) and significantly improves scroll performance and memory usage, especially for long lists like order histories. When flattening, ensure inner index variables are renamed (e.g., `recentIndex`) to avoid shadowing the outer builder's `index`.
