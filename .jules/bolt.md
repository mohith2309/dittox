## 2024-05-24 - Debouncing TextFields with Pending State Updates\n**Learning:** When adding debouncing to existing text inputs (`TextField` `onChanged`), implicit state overrides can occur if the user quickly interacts with "clear" or "recent search" buttons while a debounced keystroke is still pending. The debouncer timer will finish and overwrite the newly cleared or selected state with the outdated keystroke.\n**Action:** Always explicitly cancel any active debouncers (using `cancel()`) inside the asynchronous or explicit action handlers (like `onPressed` for clear buttons or `onTap` for recent searches) before applying the new state.
