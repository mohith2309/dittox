## 2024-05-15 - Synchronous setState in TextField onChanged\n**Learning:** In this codebase, avoid synchronous `setState()` calls inside `TextField` `onChanged` handlers that trigger filtering of large lists (e.g., Order History, Select Shops). This blocks the main UI thread and causes jank.\n**Action:** Always wrap these updates using the `Debouncer` class from `lib/utils/app_optimizations.dart`, and ensure you call `_debouncer.dispose()` in the widget's `dispose()` method to prevent memory leaks.
